# 꼬빵

두 사람이 함께 쓰는 달력형 가계부 안드로이드 앱 (Kotlin + Jetpack Compose + Firebase).

- 월별 달력에 날짜별 수입(파랑)·지출(빨강), 위쪽에 수입·지출·합계
- 날짜를 누르면 그날 내역 카드, 길게 누르면 삭제
- `+` 로 내역 추가 (지출/수입, 금액, 분류, 메모, 결제수단)
- 통계 버튼 → 이번 달 분류별 지출 도넛 그래프(범례), 날짜별 지출 막대 그래프(막대를 누르면 그날 금액), 분류별 순위
- 글꼴은 폰에서 설정한 시스템 글꼴을 따라감
- 공유 버튼 → 내 초대코드 보내기 / 상대 코드로 참여 (최대 2명, 실시간 반영, 오프라인 입력 가능)

## APK 받기

main 에 머지될 때마다 GitHub Actions 가 빌드해서 [최신 릴리스](../../releases/latest)에 `gagyebu.apk` 를 올린다.

## 공유 켜기 (Firebase 설정, 처음 한 번)

`app/google-services.json` 이 없으면 **혼자 쓰기 모드**(이 폰에만 저장)로 빌드된다.

1. https://console.firebase.google.com 에 구글 계정으로 접속 → **프로젝트 추가** → 이름 `gagyebu` → (애널리틱스는 꺼도 됨) → 만들기
2. 프로젝트 첫 화면에서 **안드로이드 아이콘** 클릭
   - Android 패키지 이름: `com.squatwolf.gagyebu` (정확히 이대로)
   - 앱 닉네임, SHA-1 은 비워 둠 → **앱 등록**
3. **google-services.json 다운로드** → 나머지 단계는 전부 **다음**/**콘솔로 이동**
4. 왼쪽 메뉴 **빌드 → Authentication → 시작하기 → 로그인 방법 → 익명** → 사용 설정 → 저장
5. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)` → **프로덕션 모드**로 시작
   - 만들어지면 **규칙** 탭에 이 저장소의 [`firestore.rules`](firestore.rules) 내용을 통째로 붙여넣고 **게시**
6. GitHub 저장소에서 `app` 폴더 → **Add file → Upload files** → `google-services.json` 올리고 커밋
7. 빌드가 끝나면 새 APK 를 두 폰에 설치 → 한 사람이 공유 버튼에서 **코드 보내기**, 다른 사람이 **참여하기**

요금은 무료(Spark) 요금제로 충분하다.

# 도착알림 (`busalarm`)

정해 둔 시간에만 경기도 버스·지하철(수인분당선 등) 도착 정보를 확인하다가, **도착 N분 전(기본 3분)** 에 알림을 보내는 안드로이드 앱.

- 알림마다 요일, 시간대(예: 평일 07:30~08:10), 몇 분 전에 알릴지를 정한다
- 버스: 정류장을 이름이나 번호로 검색 → 그 정류장을 지나는 노선 중 고르기 (안 고르면 모든 버스)
- 지하철: 노선(수인분당선 기본) · 역 이름 · 상행/하행
- 첫 화면에서 알림마다 지금 도착 정보가 30초마다 새로 고쳐짐
- 시간대가 되면 상단에 "도착 알림 대기 중"이 뜨고 화면이 꺼져 있어도 확인한다. 같은 차량은 한 번만 알린다
- 카드를 누르면 고치기, 길게 누르면 삭제

APK 는 가계부와 같은 [최신 릴리스](../../releases/latest)에 `busalarm.apk` 로 올라간다.

## 인증키 받기 (처음 한 번)

**경기 버스: 공공데이터포털**
1. https://www.data.go.kr 회원가입 → 아래 두 개를 검색해서 각각 **활용신청** (자동 승인, 보통 바로 또는 1시간 안에 사용 가능)
   - `경기도_정류소 조회`
   - `경기도_버스도착정보 조회`
2. 마이페이지 → 개발계정 → **일반 인증키(Decoding)** 복사
3. 앱 설정(톱니바퀴)에 붙여넣기

**지하철: 서울 열린데이터광장** (수인분당선도 여기서 나온다)
1. https://data.seoul.go.kr 회원가입 → 인증키 신청 → **실시간 지하철** 인증키 발급
2. 앱 설정에 붙여넣기. 비워 두면 체험용 `sample` 키로 역마다 5건만 받는다

## 알림이 늦거나 안 올 때

- 설정 → **배터리 최적화 제외** 를 눌러 허용한다
- 삼성폰: 설정 → 배터리 → 백그라운드 사용 한도 → **절전 예외 앱**에 도착알림 추가
- 알림 권한을 허용했는지, 설정의 **알림 테스트**가 오는지 확인한다
- 수인분당선은 남은 시간을 직접 주지 않아서 "[2]번째 전역", "전역 도착" 같은 메시지로 어림한다 (역 사이 약 2분). 앱에 "약 N분"으로 보이는 것이 어림값이다
- 공공데이터포털 개발계정은 하루 호출 수 제한이 있다. 앱은 차가 멀리 있으면 1분, 가까우면 25초마다 확인해서 1시간 시간대에 알림 하나당 약 60~140번 부른다
