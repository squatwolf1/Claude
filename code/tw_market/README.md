# TW 제작 시세표

화면 캡처 + Windows 내장 한국어 OCR만 사용합니다. 게임 메모리 읽기·키 입력·패킷 조작이 없습니다.

## 사용법
1. `TW_Market.exe` 실행 (항상 위 작은 창)
2. **영역 지정** → 거래소 목록의 `아이템 이름 ~ 개당 가격(남은 시간 포함 가능)` 부분을 드래그 (최초 1회, 자동 저장)
3. **부위**(투구·갑옷·무기·손목·머리·몸·손·다리·윙) + **단계**(엔키라→엔키라 칼라그→인퍼널→아퀼루스→어비스→이클립스) 선택 → 재료 입력. 시세는 장비끼리 공유.
   - **제작비 DB 저장 →** : 현재 총 제작비를 오른쪽 DB에 저장. DB 항목 더블클릭 = 상위 장비 재료로 추가(⚙ 표시, DB 값 사용)
   - 재료를 **선택한 채 스캔**하면 이름 비교 없이 맨 위 행 가격을 그 재료에 적용 (이름 오인식 대비)
4. 거래소에서 해당 아이템 검색 → **스캔** (또는 `자동(3초)` 체크)
5. 목록 맨 위 일치 행의 개당 가격 = 최저가 → `개수 × 최저가`, 총합 표시

데이터는 exe 옆 `tw_market.json`에 저장됩니다.

## 인챈트 기댓값 (장비별)
- 기대 시도 횟수 = 100 / 확률% (기본 2% → 50회). 1회 비용은 **시드**(기본 2023만 2000) 또는 **엘소**(기본 3035) 선택
- **일반 주문서**: 주문서 1장 + 50 × 1회 비용 (성공 시에만 소모)
- **일회용 주문서**: 50 × (주문서 + 1회 비용) (매 시도 소모)
- 위 값 × **필요 성공 횟수**. 시드와 엘소는 합산하지 않고 따로 표시
- 둘 중 라디오로 선택한 쪽만 총 제작비에 반영, 두 기댓값은 총 제작비 아래 줄에 표시
- 재료 삭제: 표에서 선택 후 Delete 키

## 빌드
- GitHub Actions `Build TW_Market` 의 Artifact에서 exe 다운로드, 또는
- Windows에서 Python 3.11 설치 후 `build.bat`

OCR 오류 시: 설정 > 시간 및 언어 > 언어 > 한국어 > 언어 옵션에서 광학 문자 인식(OCR) 설치.

## 가격이 안 읽힐 때
스캔 후 **인식 확인** → OCR 원문/해석 결과와 `scan_debug.png`(캡처 이미지)를 확인하세요. 영역은 별표·아이콘을 빼고 `아이템 이름`~`남은 시간` 칸만, 헤더 없이 잡는 것이 가장 정확합니다.
